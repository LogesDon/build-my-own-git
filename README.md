# build-my-own-git
Side project where I build my own git from scratch.
This is to help with my conceptual understanding of how git works. 

Original Tutorial Link: [Build Your Own Git](https://kushagra.dev/blog/build-git-learn-git/)


## Changes Added By Me 
* git log --oneline functionality
* git status functionality
* git branch -d functionality

## Other Information
1. This project is solely for the purpose of enhancing my understanding of how 
git works under the hood. 
2. The tests for this project are quite bare-bones, not comprehensive.
